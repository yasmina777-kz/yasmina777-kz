# Building tools for learning

AI-powered education apps, interactive lectures, and web interfaces.

My repositories explore how software can support teaching and learning: from classroom APIs and real-time chat to multilingual lessons with voice and avatars.

## Selected projects

| Project | What it does | Stack |
| --- | --- | --- |
| [AI Mentor](https://github.com/yasmina777-kz/lecturer-app) | Interactive lectures, voice questions, notes and practice in Russian, English and Kazakh. | React · TypeScript · ASP.NET Core · EF Core |
| [Chatra — backend](https://github.com/yasmina777-kz/chatra-with-avatar-B) | Education platform API with classes, assignments, AI grading, real-time chat and teacher-avatar lectures. | Python · FastAPI · SQLAlchemy · WebSockets |
| [Chatra — frontend](https://github.com/yasmina777-kz/chatra-with-avatar-F) | Web interface for the Chatra education platform, paired with the backend above. | Vue 3 · Nuxt 3 · Pinia |
| [Portfolio](https://github.com/yasmina777-kz/portfolio) | Personal website with separate pages for projects, experience and contact. | HTML · CSS · JavaScript |

## Technologies in these projects

**Frontend:** TypeScript, JavaScript, React, Vue, Nuxt, HTML, CSS  
**Backend:** Python, FastAPI, C#, ASP.NET Core, SQLAlchemy, Entity Framework Core  
**Data & integrations:** SQLite, PostgreSQL, WebSockets, AI APIs, speech services
